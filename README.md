## Projects

**[Agentic Grove](https://github.com/Adiezc/agentic-grove)** · [download for Mac](https://github.com/Adiezc/agentic-grove/releases/latest)\
A calm desktop cockpit for AI agents. Your projects stand as runestones, your agents live in a
world tree and amber light means something needs you. TypeScript, Electron and Three.js; runs
locally, no telemetry.

**[How the European Parliament votes on China](https://github.com/Adiezc/ep-china-votes)**\
Every roll-call vote on China, Hong Kong and Taiwan since 2019: 179 votes, 126,672 MEP votes.
The Parliament's China consensus did not soften after the 2024 election. It was outvoted.
Python, with a thirteen-slide briefing.

**[Anthill](https://github.com/Adiezc/ANThill-Sim)** · [try it live](https://adiezc.github.io/ANThill-Sim/)\
An agent-based simulation of a Florida harvester ant colony, built from the published science.
Every number in the model says which study it came from. TypeScript, runs in the browser.

**[Raid the Watchtower](https://github.com/Adiezc/raid-the-watchtower)** · [v1.0.0 release](https://github.com/Adiezc/raid-the-watchtower/releases/tag/v1.0.0)\
An AI red/blue agent swarm, directed by a human, that studies six security threats
(BOLA, phishing, trojans, worms, DDoS, prompt injection) inside a fictional story.
Runnable local lab, Python standard library, all data synthetic.
